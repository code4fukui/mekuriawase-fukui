# 福井めくりあわせ (Fukui Mekuriawase)

福井県の観光スポットのイラストを使ったカードめくり記憶ゲームです。目的は、観光地の名前カードとそれに対応するエリア（地域）カードをマッチさせることです。

## デモ

実際のゲームプレイはこちら: **https://github.com/code4fukui/mekuriawase-fukui

## 遊び方

16枚の伏せられたカードがグリッド状に表示されます。各観光地は同じイラストが描かれた2枚1組のカードで構成されており、1枚には観光地の「名前」、もう1枚にはその「エリア」が書かれています。カードをめくって対応するペアを見つけ、できるだけ早くすべてのカードをクリアしましょう。

## 特徴

- **ユニークなマッチングシステム:** 共通のイラストをヒントにして、観光地の名前とエリアをマッチさせます。
- **動的なボード:** 16枚のカード（8ペア）は、ゲーム開始時に毎回自動的にシャッフルされます。
- **クリアタイム:** すべてのペアを揃えると、アラートのポップアップでクリアタイムが表示されます。
- **シンプルなインターフェース:** すっきりとしたレスポンシブデザインを採用し、「リトライ！」ボタンからすぐに新しいゲームを開始できます。
- **スムーズなアニメーション:** CSSを活用した3Dのカードめくりエフェクトを実装しています。

## データと依存関係

- **ゲームデータ:** [福井観光スポットオープンデータ](https://github.com/code4fukui/fukui-spot)（CSV形式）を使用しています。
- **JavaScriptモジュール:** [js.sabae.cc](https://js.sabae.cc) の `shuffle.js` および `CSV.js` を利用しています。
